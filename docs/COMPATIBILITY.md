# Compatibility

Target: PocketMine-MP API 5.x.

API compatibility alone does not guarantee that a fork works. Initial manual validation targets include PocketMine-MP 5.44.x and Altay 5.45.1 (protocol 2225), but neither target is runtime-certified by this baseline.

Before claiming support for a build, test open, close, clicks, cancellation, reconnect/disconnect, multiple players and storage transactions on a staging server.
